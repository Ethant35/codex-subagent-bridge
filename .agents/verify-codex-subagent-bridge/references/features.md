## Reading the evidence

The script stores typecheck and test transcripts, archive hash, hashes of the tested source/tests, installed runtime byte comparisons, CLI stdout/stderr/exits, runtime/platform and teardown status. The script fails on a mismatch; preserve its partial evidence on failure. Inspect test summaries for all external skips. The feature map expresses required outcomes, not a claim that a future run passed them.

For an import change, trace setup through `guided`/`local-commands` to filesystem helpers and separately through runner/store/file-tools. The decisive assumption is that setup can avoid SQLite without changing persisted lifecycle behavior. Setup warning checks plus the existing storage/MCP/recovery tests cover both sides. For output changes, preserve machine keys, codes and exit status while allowing the deliberately improved human text and actionable `next` string.
